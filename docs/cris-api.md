# CRIS API

Primarily used by `Elsevier Pure` CRIS.

## Endpoints

- `GET  /projects/:uuid`
- `PUT  /projects/:uuid`
- `POST /projects/search`


- `PUT  /applications/:uuid`
- `GET  /applications/:uuid`
- `POST /applications/search`


- `PUT  /awards/:uuid`
- `GET  /awards/:uuid`
- `POST /awards/search`

---

- `GET /organizations/:uuid`

- `POST /persons/search`
- `POST /external-persons/search`

- `GET /users/:uuid`
